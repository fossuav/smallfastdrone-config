Added `@types/w3c-web-serial` (Web Serial isn't in standard lib.dom yet) and registered it in tsconfig.app.json. ConnectView footer message updated from "Real-drone (USB) support arrives in a later slice" to instructions for both USB and SITL flows. **Written blind — no bench device handy.** SITL E2E still green, so the production code path is uncontaminated; real-hardware verification is on the operator's side when convenient.
